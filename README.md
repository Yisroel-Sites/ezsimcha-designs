# EZ Simcha Designs

Simcha invitation maker: pick a design, type your names, download.

Static site, no build step. Deploys on Vercel as-is.

- `index.html` - the whole app (editor, gallery, video maker)
- `ezdata.js` - sample index, ready text, elements, fonts
- `gen.js` - procedural backgrounds
- `ex/<simcha>.json` - exact layouts for each simcha's designs
- `bg/` - background images
